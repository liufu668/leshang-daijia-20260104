\section{\faUsers\ 项目经历}
\subsection*{\textbf{乐尚代驾 | 微信小程序后端}}
乐尚代驾是一款提供酒后代驾、商务代驾服务的微服务后端项目，包含乘客端、司机端，实现下单、派单、抢单、支付等业务，并在接口性能、缓存稳定性、并发安全和数据一致性方面做了实际优化。


核心技术栈：SpringBoot + SpringCloud(Gateway/Feign/Sentinel) + MyBatis-Plus + MongoDB + Redis + RabbitMQ + Redisson
\begin{itemize}[parsep=0.5ex]

\item 乘客下单优化：针对原接口响应慢、缓存不稳定问题，基于 CompletableFuture 实现订单创建与派单异步解耦，用定时补偿任务保障派单可靠性；提前在预估订单阶段缓存订单信息到 Redis；通过缓存空值、分布式锁+双重检查、随机过期解决缓存穿透、击穿、雪崩问题；优化业务线程池与 Redis 连接池参数，QPS 从 120+ 提升至 250+，响应时间从 330ms 降至 150ms。

\item 司机匹配优化：使用 Redis GEO 存储司机实时位置，实现高效地理检索；定时批量同步位置至 MongoDB 持久化；针对原循环远程调用查询司机位置导致接口响应极慢、高并发下性能瓶颈问题，重构循环远程调用为批量查询+本地内存过滤，消除性能瓶颈，QPS 从 20+ 提升至 230+，响应时间从 2.5s 降至 200ms。

\item 司机抢单优化：针对高并发下重复接单、超卖问题，使用 Lua 原子脚本 校验 Redis 抢单标识；引入RabbitMQ异步削峰解耦数据库，开启生产者Confirm保证消息可靠投递；消费者手动ACK配合订单状态机+MySQL乐观锁做幂等控制；配置死信队列隔离重试失败消息，并通过定时巡检任务做最终兜底，保障数据一致性；160 线程压测 QPS 稳定 500+，业务错误率 0 \%。

\item 支付安全优化：针对支付环节优惠券在未支付成功前即被核销，支付失败或超时无法回退的问题，改为支付前预占锁定优惠券、支付成功后正式核销；通过支付查询自动释放 + 定时任务关单回收，保证订单与券状态一致，避免资源锁定与券损失。

\item 微服务高可用：针对流量突增、服务抖动可能引发的微服务雪崩问题，
基于 Sentinel 构建网关层 + 微服务层双层限流降级体系；核心接口单独设置差异化限流阈值；Gateway 实现全局限流、黑名单过滤；Feign 调用配置熔断降级，服务异常返回兜底结果，防止服务雪崩。

\end{itemize}
