# 核心备考逻辑：**以你的代驾项目为主线，反向牵引八股，不单独死记零散八股**
中小厂面试90%提问都围绕你的项目展开，纯孤立八股很少单独深挖，这么准备效率最高，不会白学。

## 一、第一优先级：顺着项目每一块，反向深挖配套八股（70%时间）
按你简历五大模块拆分，每一块绑定必背底层知识点，面试一问你项目，你能顺理成章讲底层原理：
### 1. 下单异步、线程池、CompletableFuture → Java并发JUC八股
配套深挖点：
1. CompletableFuture异步原理、异常处理、线程池参数怎么调？核心参数corePoolSize、max、队列、拒绝策略，你项目里为什么选这个配置？
2. synchronized、Lock、AQS、volatile区别；
3. 线程池四种拒绝策略分别适用场景；
4. 什么是死锁，如何排查、避免；
5. JVM内存模型、GC、OOM场景（线程池无限创建线程导致OOM）。

### 2. Redis全套优化（缓存三大问题、分布式锁、GEO、Lua脚本）→ Redis核心八股
配套深挖点：
1. 缓存穿透/击穿/雪崩：你三种方案的优缺点，布隆过滤器为什么没选用？
2. Redisson分布式锁底层（可重入、锁超时、锁续命）；
3. Lua脚本保证原子性原理，为什么多条Redis命令不加Lua会并发超卖；
4. Redis GEO底层结构、精度、距离检索逻辑；
5. Redis持久化RDB/AOF、宕机数据丢失问题；
6. Redis过期策略、内存淘汰策略。

### 3. 司机批量查询RPC、SpringCloud Gateway、Feign、Sentinel → 微服务八股
配套深挖点：
1. Feign调用流程、超时、重试问题；
2. Gateway网关限流实现、全局过滤器；
3. Sentinel限流、熔断、降级底层；滑动窗口原理；
4. 微服务雪崩产生原因，双层限流为什么能防护；
5. 服务之间调用超时如何排查。

### 4. RabbitMQ削峰、可靠消息、死信队列、消息幂等 → MQ八股
配套深挖点：
1. 生产者Confirm、持久化、手动ACK分别解决什么丢失问题；
2. 消息重复消费怎么处理（幂等）；
3. 死信队列使用场景，你项目里哪些消息会进死信？
4. MQ积压如何排查、解决；
5. 异步解耦对比同步接口的优缺点。

### 5. 订单状态机、乐观锁、优惠券预占、数据一致性 → MySQL八股
配套深挖点：
1. MySQL MVCC、事务隔离级别，你业务用的哪一级，为什么；
2. 乐观锁version原理，高并发下乐观锁失效场景；
3. 索引底层B+树，什么场景会索引失效；
4. 慢查询排查思路；
5. 分布式数据一致性方案（本地消息表、可靠消息最终一致性），你预占优惠券属于哪种思路。

## 二、第二优先级：通用基础八股（25%时间，只背中小厂高频，不深挖冷门）
不用全网乱刷，只抓高频基础，作为项目之外的补充提问：
1. Spring：IoC容器、AOP实现原理、事务传播机制、事务失效场景；
2. Java基础：集合（HashMap底层、扩容、红黑树）；
3. 计算机基础：TCP三次握手四次挥手、滑动窗口、HTTP1.1/2区别；
4. Linux基础：查看端口、日志、内存占用简单命令（看得懂日志排查即可）。

## 三、第三优先级：算法（5%，极简维持手感）
你目标中小厂，不用刷中等困难题，每天1道简单题：数组、链表、二分、哈希表，能手写基础逻辑就行，不用花大量时间。

## 四、面试额外两大必准备内容（极易被问，不属于八股但决定通过率）
1. **Gap一年完整话术**
   统一逻辑：去年毕业发现缺少分布式实战，全职打磨微服务代驾项目，持续写博客复盘技术，补齐高并发、缓存、消息队列实战能力，随时到岗稳定长期发展。
2. **项目踩坑复盘（拉分关键）**
   每一个优化点，强制自己梳理三段话：
   ① 原始业务出现了什么故障、造成什么影响；
   ② 你尝试过哪些方案，为什么放弃别的方案选当前方案；
   ③ 改造后遇到了什么新bug，怎么排查、解决。
   面试官最爱听踩坑、排障过程，纯背参数会扣分。

## 五、每日学习分配方案（直接照做）
1. 3小时：深挖项目模块+绑定对应底层八股，边梳理边自问自答；
2. 1小时：通用基础八股复盘；
3. 20分钟：简单算法刷题；
4. 碎片时间：反复背诵Gap话术、谈薪话术。

## 六、避坑提醒
1. 不要分开两头学：不要先刷完整本八股，再回头看项目，效率极低；一定要**项目带八股**，学到哪块业务，同步吃透对应底层；
2. 不要只背标准答案：结合你代驾业务举例，比如问缓存雪崩，直接说“我代驾下单高峰期就遇到过，当时我用随机过期+分布式锁解决……”，结合项目回答会大幅加分；
3. 不用学冷门技术：分库分表、Elasticsearch、Kafka复杂特性等中小初级岗很少问，现阶段可以放一放。
