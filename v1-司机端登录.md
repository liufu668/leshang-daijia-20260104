# **司机端登录与认证**

## **主要实现功能**

### **司机微信授权登录**
1. 配置微信小程序相关依赖与配置
2. 编写微信小程序登录接口，接收 `code` 并调用微信API获取 `openid`。
3. 实现司机登录逻辑：
    - 根据 `openid` 判断是否为首次登录。
    - 首次登录需初始化司机信息、司机设置、司机账户。
    - 记录登录日志。
4. 返回Token给前端。
5. web-driver(DriverController)
```java
@Operation(summary = "微信小程序登录")
@GetMapping("/login/{code}")
public Result<String> login(@PathVariable String code) {
   log.info("前端返回的登录码,code: {}" + code);
   return Result.ok(driverService.login(code));
}
```

### **获取司机登录信息**
1. 实现接口：根据 wxOpenId 获取司机基本信息。
2. 判断司机是否已录入人脸模型（用于后续人脸识别）。
3. 返回司机信息及人脸录入状态。
4. web-driver(DriverController)
```java
@Operation(summary = "获取司机登录信息")
@GetMapping("/getDriverLoginInfo")
public Result<DriverLoginVo> getDriverLoginInfo() {
    Long id = Long.parseLong(SecurityContextHolder.getContext().getAuthentication().getName());
    log.info("从上下文获取到的司机ID: {}", id);
    DriverLoginVo driverLoginVo = driverService.getDriverLoginInfo(id);
    return Result.ok(driverLoginVo);
}
```

### **腾讯云对象存储（COS,Cloud Object Storage，COS）集成**
#### 背景知识
- 官方文档:https://cloud.tencent.com/document/product/436/10199
- 腾讯云对象存储（COS）是一种安全、稳定、高效、易用的云存储服务，适用于海量数据存储、静态网站托管、内容分发等场景。
- 集成COS可帮助开发者在应用中实现可靠的文件存储与管理。


#### 核心业务流程
1. 开通腾讯云COS服务，创建私有存储桶。
2. 获取腾讯云访问密钥（SecretId、SecretKey）。
3. 编写COS上传接口：
    - 接收上传文件（MultipartFile）。
    - 将文件上传至COS指定路径。
    - 返回文件路径(在COS的存储路径)和临时访问URL。
4. 编写获取临时签名URL的接口，用于前端回显图片。
5. web-driver(CosController)
```java
//文件上传接口
@Operation(summary = "上传")
@PostMapping("/upload")
public Result<CosUploadVo> upload(@RequestPart("file") MultipartFile file,
                                  @RequestParam(name = "path", defaultValue = "auth") String path) {
    CosUploadVo cosUploadVo = cosService.uploadFile(file,path);
    return Result.ok(cosUploadVo);
} 
```
6. 数据链路:
```text
前端页面
    ↓ (选择文件 + 选择分类)
前端调用 POST /cos/upload
    ↓ (MultipartFile + path参数)
(web-driver)CosController.upload()
    ↓ (参数验证)
(service-driver)CosServiceImpl.upload()
    ↓ (1) 创建COSClient
    ↓ (2) 生成唯一文件名
    ↓ (3) 上传到私有存储桶
    ↓ (4) 内容安全审核
    ↓ (5) 生成临时URL
    ↓ (6) 构建返回VO
返回Result<CosUploadVo>
    ↓
前端接收 → 显示临时图片 + 保存URL到表单
    ↓
表单提交 → 调用(web-driver)updateDriverAuthInfo 接口,保存COS路径到数据库
(前端先把所有文件都传上去拿到地址，等用户填完所有信息再一次性提交表单。
所以在调用CosServiceImpl.upload()时先不急着将数据保存到数据库)
    ↓
后续访问 → 通过getImageUrl()获取新临时URL
```

### **腾讯云OCR集成（身份证识别）**
#### 背景知识
- 官方文档: https://cloud.tencent.com/document/product/866/33524
- 腾讯云OCR（光学字符识别）服务能够自动识别身份证图像中的文字信息，并提取结构化数据，广泛应用于实名认证、信息录入等场景。


#### 核心业务流程
1. 司机注册成功之后，去做实名认证
2. 开通腾讯云OCR服务。
3. 编写身份证识别接口：
    - 接收身份证正面或反面图片。
    - 调用OCR API识别信息（姓名、性别、身份证号、有效期等）。
    - 将识别后的图片上传至COS。
    - 返回识别结果及图片路径。
4. 支持正反面分别识别。
5. web-driver(OcrController)
```java
@Operation(summary = "身份证识别")
@PostMapping("/idCardOcr")
public Result<IdCardOcrVo> uploadDriverLicenseOcr(@RequestPart("file") MultipartFile file) {
    return Result.ok(ocrService.idCardOcr(file));
}
```
6. 数据链路:
```text
用户上传图片 (前端)
    ↓
 (web-driver)MultipartFile接收
    ↓
(service-driver)OcrServiceImpl处理层
    ├── 1. 图片转Base64编码
    ├── 2. 构建腾讯云OCR客户端
    ├── 3. 调用OCR识别API
    ├── 4. 解析识别结果
    ├── 5. 上传原图到COS
    └── 6. 返回结构化VO对象
    ↓
前端接收 → 自动填充表单
```

这个错误是典型的 MyBatis-Plus 版本兼容问题
从mybatis-plus官网找到正确的依赖导入(注意名称和版本)

**解决:**
删掉如下:
```xml
<dependency>
<groupId>com.baomidou</groupId>
<artifactId>mybatis-plus-boot-starter</artifactId>
<version>3.5.7</version>
</dependency>
```

替换如下:
```xml
        <dependency>
            <groupId>com.baomidou</groupId>
            <artifactId>mybatis-plus-spring-boot3-starter</artifactId>
            <version>3.5.15</version>
        </dependency>
```


## 错误3: github提交

**分析问题:**
common-account.yaml里的敏感信息,提交到暂存区后,推送到github远程仓库被拒绝.
而且多次提交导致推送失败的提交内容没删干净

解决方案:

```bash
# 查看提交历史 
git log --oneline

# 硬重置到 73c5f87 提交，将后面的失败提交全部删掉（会影响到本地IDEA里的项目）
git reset --hard 73c5f87

# 回到IDEA里还原项目今天的修改，重新提交推送
```
